MODERN MYTHOLOGY · TOOLS

authoring + instrument tools that live alongside the game. open any in a browser.
QUICKSTART · RIFFMASTER (PDP / PS5 GUITAR)
1. Plug the wireless dongle into a USB port. Press SYNC on the dongle then PS on the guitar to pair. 2. Open any instrument below. Click anywhere on the page once — the audio engine needs a user gesture to start. Look for the AUDIO: RUNNING badge. 3. Press a fret — the overlay (bottom-right) will show what button index your driver reports. Use DETECT 10 FRETS / SET OCTAVE MOD / DETECT WHAMMY on the synth tool to calibrate if needed; the mapping is shared across all instruments. 4. If strum just moves menus instead of playing, your driver is emitting arrow keys — toggle the arrows = strum checkbox in the overlay.
QUICKSTART · M-VAVE FM-1 (ANY FIRMWARE — SEE THE ATLAS)
0. Installing a firmware? Browse the FIRMWARE ATLAS, then run godot/tools/fm1_flash.sh in Desktop Mode — it lists every installable firmware, preflights cable / hub / power, blocks sleep, opens that firmware's own installer and verifies the result. On multi-track firmwares (Felucca and its forks) the tools route by instrument automatically, following each firmware's default tracks: bass → track 1, chords → 2, lead → 3, drums → its drum channel. 1. USB-C the FM-1 to the machine, power it on in normal play mode (not the updater — if a port called ota-FM-1 shows up, finish the flash and power-cycle). 2. Open any instrument in Chrome or Edge (Web MIDI — same requirement as the Baud Girl installer). Allow the MIDI prompt; say yes to SysEx too if you want to push patches. 3. The FM-1 · MIDI panel (bottom-right, left of the Riffmaster panel) should read connected. Its keys now play the instrument. Pick the port by hand if it enumerated as a bare USB Composite Device. 4. Knobs: neither firmware documents CC output, so select a slider in the panel, click LEARN, turn the knob. Mappings are saved and shared across every tool. 5. Tick OUT→FM-1 to mirror what the instrument plays to the FM-1's own 6-op engine — Riffmaster guitar in, hardware DX7 out. Open FM-1 CONSOLE for the monitor, program change, and DX7 patch push.

RIFFMASTER INSTRUMENTS · play in the browser with the PDP guitar controller, the M-VAVE FM-1 keys, or click/keyboard

RIFFMASTER SYNTH
Monophonic legato lead. Frets pitch the held note; strum re-attacks; hammer-on / pull-off when you change frets without strumming; whammy = real pitch bend. 8 voice presets.
guitarsynth
RIFFMASTER DRUMS
10 synthesised drum voices on the fret pads. Strum hits the highest held pad with velocity. 16-step sequencer with swing for laying patterns under live play.
guitardrums
RIFFMASTER ARP
Arpeggiator. Hold frets — held notes arpeggiate. Strum cycles direction (up / down / up-down / random). Whammy modulates rate. Six timbre presets.
guitararp
RIFFMASTER THEREMIN
Continuous-pitch instrument. Whammy bends ±1 octave around an octave-fret base. Five voice presets, adjustable vibrato. Strum toggles the voice for sustained drones.
guitartheremin
RIFFMASTER BASS
Dedicated low-end monophonic bass. Sub-oscillator stacked per voice, six presets (Finger / Pick / Slap / Synth / Sub / Growl), velocity from fret pressure, whammy = mute/dampen filter sweep. Default root D2; selectable down to E1.
guitarbass
RIFFMASTER DEMONS
Eight demon micro-motifs from the Magician roster (vagrant / cicada / moth / steamboat / weir / filly / starling / husk) plus the steamboat-finale + full-moon-drone cinematic textures. Frets fire one-shots; LOOP mode round-robins held demons.
guitardemons
RIFFMASTER CHORDS
Progression walker. 10 classic progressions (i-VI-III-VII, ii-V-I, doo-wop, andalusian, cathedral, drone…). Strum plays the current chord and advances to the next; frets jump directly to a step. 5 voicings, 5 voice timbres, whammy = filter brightness.
guitarchords
RIFFMASTER DRONES
Polyphonic harmonic layerer. Each fret toggles a sustained voice (root / 5th / octave / ♭3 / ♭7 / 9th / 11th…). Build up the cathedral by adding voices; strum silences all. Six pad patches; whammy = master lowpass; shimmer slider spreads detune.
guitardrone
RIFFMASTER LOOPER
4-track event recorder. Click a track to arm, strum to record events, click again to commit + start looping. Tracks loop independently with their own timing; shift-click cycles a track's voice (lead / bass / bell / pluck). Right-click stops + clears.
guitarlooper
RIFFMASTER STRINGS
Karplus-Strong physics-modelled plucked string. Sounds like a real guitar / lute / koto / ukulele depending on the preset (six). Each strum plucks the string at the current fret; decay + brightness + body resonance are continuously adjustable. Whammy modulates brightness.
guitarstrings
RIFFMASTER FM
2-operator frequency modulation. Carrier + modulator with adjustable ratio + index + mod-decay. Eight presets cover electric piano / bell / brass / marimba / wood block / metal pad / glass voice / FM growl — timbres subtractive synths can't reach. Whammy boosts the modulation index live.
guitarFM

OTHER INSTRUMENTS · keyboard / mouse / touch

TAROT SYNTH
22-card synth pad with 4 banks (Diner / Cathedral / Riverboat / Pastoral). Multiple play modes (CARD / SCALE / GUITAR), chord mode, 4-lane 16-step sequencer, gallery-card art swap.
synthguitar
FM-1 CONSOLE
Bridge for the M-VAVE FM-1 hardware synth (stock, Baud Girl FM-1+VA, Felucca or SLOOP firmware — auto-detected). Port picker + status, read-only firmware IDENTIFY, MIDI monitor with decode, four-slot knob CC learn (shared with every instrument), program change, on-screen keyboard mirroring the FM-1's keys, and DX7 single-voice SysEx push of the RIFFMASTER FM presets to the hardware engine.
FM-1MIDI
AMBIENT SYNTH
Chapter-drone generator. 4 tonal voices + 1 noise-floor layer per preset. Live play OR offline-render to WAV (90-300s loopable). 8 presets seeded to the music catalog.
drone

RECORDING · tape loops and the world outside

TAPE STUDIO
Bento-style eight-track tape loop machine. Overdub / replace with tape-loop decay, resample the master into a track, count-in + click, per-track DJ filter / drive / crush / echo / verb sends, a master tape stage (saturation, wow, flutter, hiss, age, glue), a hold-to-shred stutter, MIDI clock out so SLOOP / Felucca / X0X follow it, PRINT the master into the library or straight into the game as a seamless loop.
tapeFM-1 clockloops
FIELD RECORDER
Record the world on the Deck (or a USB recorder / the FM-1's USB audio): raw input, pre-roll so you never miss the moment, markers, slate metadata with locale, tags and location. Clean it — trim, high-pass, spectral denoise, loudness, fades — make a seamless loop, and write it straight into the game, including the WANTED list of catalog tracks that still have no audio.
fieldambience
FM-1 FIRMWARE ATLAS
Every firmware for the M-VAVE FM-1 the tools know: stock, FM-1+VA, Groove OS, Felucca and its forks (SLOOP, SLOOP ALG, X0X, Jangada, Melodee), research builds and game ports — install links, MIDI maps, DX7 support, recovery. One button reads which one is on your synth.
FM-1reference
SD-card takes from a Zoom / Tascam and browser downloads go in with python3 godot/tools/field_ingest.py (wanted · scan · ingest · fill).

Each tool is a single self-contained HTML file. The Riffmaster instruments share gamepad_input.js for HID gamepad polling, axis-as-button bridging, and the controller-overlay debug panel, and midi_input.js for Web MIDI (FM-1 port auto-select, note / CC / bend events, CC learn, OUT echo). fm1_dx7.js builds DX7 voice SysEx for the FM-1's Dexed core. Drop the device on any browser tab to play. Not yet MIDI-wired: THEREMIN, CHORDS, DRONES, AMBIENT (no natural key→pitch mapping yet).
