SEND copies one file into godot/assets/audio/drive/ — music also gets a FROM THE DRIVE entry in the in-game music player. SAVE backs those files up to the project's Drive folder and commits only the catalog line + the record (godot/tools/audio_sent.json); no audio goes into git. REMOVE takes a file back out of the game; nothing on your Drive is ever changed or deleted. Rows marked in game without a REMOVE are files the game already ships (same bytes). Duplicates (the same bytes in several folders) are hidden unless you tick the box.
