FIRMWARE

Press IDENTIFY to read the firmware version from the synth (read-only), or pick it by hand. Saved in this browser.
Installing Baud Girl's firmware? On the Deck, run godot/tools/fm1_flash.sh — it checks cable / hub / power, blocks sleep, opens her installer in a clean Chrome profile, and verifies the result. The flash itself happens in her installer, never from these tools.

KNOBS · CC LEARN

Neither firmware documents whether the four knobs transmit CC. LEARN a slot, turn the knob: if a CC lands it's mapped (and shared with every instrument tool). If nothing lands while the monitor stays quiet, that firmware keeps knobs local.

PRESET · PROGRAM CHANGE

128 factory tones on stock (reportedly the DX7 ROM1A bank in slots 0–31). Program change is the only way to pick a preset from the tools — selecting on the synth sends nothing back.

PATCH PUSH · riffmaster FM presets → DX7 voice dump

select a preset to see its SysEx.
Builds a 155-byte single-voice VCED (F0 43 1n 00 01 1B … F7): algorithm 1, OP1 carrier + OP2 modulator, OP3–6 silenced. The 2-op tool's ratio → coarse/fine, index → modulator output level, decays → EG rates. Unverified on hardware — the Dexed core accepts this format; whether the FM-1 firmware forwards it to the engine (and into the edit buffer vs. a stored slot) is what you're testing. Nothing here touches the FM-1's own 00 32 45 vendor SysEx (that's the updater protocol). Stock firmware has no dump read-back, so nothing you push can be verified except by ear.
