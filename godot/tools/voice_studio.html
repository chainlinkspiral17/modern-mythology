3 · Export

When you have audio for the lines you want, click Export drop-in zip. The zip contains assets/audio/voice/<scene>/NNN.ogg files + a snapshot of the scene JSON. Put it on Google Drive and run bash godot/tools/import_voice_dropins.sh on the Deck — it matches every line to the scene as it is now (do not unzip it over godot/: the snapshot would overwrite later edits).

How to use: Drop a scene JSON on the left (e.g. vol1_ch10_longboat.json, meld_seam_1_2.json, vol5_prelude_arcana_ep07_backyard_dogs.json). For ElevenLabs, first import tools/voice_map.json so names, aliases and per-volume narrators (_narrator_vol1…, _narrator_whispers) resolve exactly as elevenlabs_render.py does. Each voiceable line gets a row below — pick a method on the left, then record / upload / generate per line. When you're done, hit Export drop-in zip on the left — on a desktop checkout unzip it inside your godot/ folder; for the Deck, put the zip on Google Drive and run bash godot/tools/import_voice_dropins.sh (voice audio rides the Drive, not git).
