# godot/qa · THE LENS

Arc 0 of `lore/_VISUAL_PROGRAM.md`: every VN framing seen, not only
measured.

| file | what |
|---|---|
| `contact_manifest.json` | the shot list — generated by `tools/audit/contact_manifest.py`, committed. One entry per preset a chapter uses (its scene, volume, uses, the moods the chapters cue there, the markers it owns) plus every hero GLB × Portrait3D expression. |
| `contact/` | the frames — produced on the Deck by `tools/contact_sheet.sh`, **gitignored on the working branch**, pushed to the orphan branch `qa/contact` by `tools/contact_push.sh`. `contact/<preset>/<mood>__establish.jpg`, `contact/<preset>/<mood>__<marker>.jpg`, `contact/_heroes/<glb>__<expression>.png`, and `contact/_report.json` (what was skipped and why). |

The Deck, in one paste after a pull:

```bash
cd /home/deck/Downloads/modern-mythology/godot/tools/blender && ./list_stale_builds.sh && cd .. && ./contact_sheet.sh && ./contact_push.sh
```

(`list_stale_builds.sh` prints the rebuild loop; run it first when it
lists anything, or the sheet photographs stale rooms.)

Claude then:

```bash
git fetch origin qa/contact && git show origin/qa/contact:godot/qa/contact/_report.json
git show origin/qa/contact:godot/qa/contact/cabin_interior/candlelight_low__establish.jpg > /tmp/x.jpg
```

and reads the frames. A frame is the room, its lights and its
PostProcess stack as the VN's texture layer receives it — not THE
TRIP, not the dialogue box, not the busts.
